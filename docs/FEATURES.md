# Feature backlog (product)

Prioritized ideas for the native app. Not all land in MVP.

## Must-have (MVP)
- Google Sign-In
- Multi-language **app UI**
- Onboarding wizard
- Gemini API key setup guide
- Start/Stop live dub
- Target language list
- Foreground service + notification
- Clear error states (quota, mic denied, network)

## Should-have
- In-app YouTube / URL player with picture offset control
- Session history (local)
- Gender/voice quality notes (honest: model-dependent)
- Battery / latency indicators

## Later
- Play Billing (Pro)
- Team / family plans
- Wear / tablet layouts
- Optional cloud proxy so users never paste raw API keys (if product decides)
