# User journey — first session script (for UX/copy)

Use this as the script writers / Compose UI copy source. Localize every string.

## Welcome
- Title: Live dubbing, in your language
- Body: ParsLiveDub listens to what’s playing and speaks a live translation. Setup takes a few minutes.
- Primary: Get started

## Google
- Title: Sign in with Google
- Body: Secure your settings and finish setup faster.
- Primary: Continue with Google

## Permissions
- Title: A few permissions
- Body: We only use these while you are dubbing. You can revoke them anytime in system settings.

## API key
- Title: Connect Gemini
- Body: Gemini is the AI that translates speech. You need a free API key from Google AI Studio — we’ll open the page and wait for you to paste it here.
- Primary: Open Google AI Studio
- Secondary: I have a key → paste

## Test
- Title: Testing connection…
- Success: Connected. You’re ready to pick a language.
- Fail: That key didn’t work. Double-check you copied the full key.

## First video
- Title: Play something to dub
- Body: Open a video (or paste a link). Then press Start dubbing. A short delay is normal.
- Primary: Start dubbing

## Success
- Title: You’re all set
- Body: Next time, just open a video and hit Start. Change language or API key anytime in Settings.
